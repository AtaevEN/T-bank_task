# 📝 Тестовое задание Tinkoff (NLP)

## 📌 Задача  
Классификация текстовых строк по **9 категориям**.  
Входные данные — тексты на русском языке.

---

## 🔧 Решение  

### 1. Предобработка текста
- Очистка текста от спецсимволов, чисел и пунктуации (регулярные выражения).  
- Лемматизация с помощью **pymorphy2** и **Mystem**.  
- Удаление стоп-слов.  

### 2. Автоматическая разметка
- Использована предобученная модель из **HuggingFace Transformers** для автоматической разметки текстов.  
- Для увеличения объёма выборки создан синтетический датасет с помощью генерации парафраз (T5).  

### 3. Моделирование
- Для классификации по 9 категориям использована **та же предобученная модель**, что и для разметки, но обучалась уже на размеченных данных (без zero-shot).  
- Токенизация текстов с помощью `AutoTokenizer`.  
- Дообучение модели `AutoModelForSequenceClassification`.  
- Использование подхода **LoRA (Low-Rank Adaptation)** для повышения эффективности обучения.  
- Параллельно применялась генеративная модель T5 для расширения обучающей выборки через парафразы.

### 4. Обучение и валидация
- Разделение данных на обучение и тест (`train_test_split`).  
- Метрики: `accuracy`, `f1_score`, `classification_report`.  
- Обучение модели через `Trainer` и `TrainingArguments`.
